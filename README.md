🧠 AI Sentiment Analyzer
A production-ready Sentiment Analysis Web App built using Machine Learning + NLP.
Users can enter review text and instantly get sentiment prediction with confidence score.
🚀 Features
Binary sentiment classification (Positive / Negative)
TF-IDF + Naive Bayes model
Animated, modern UI (glassmorphism + gradients)
Confidence score with progress animation
Flask web app deployed on Render
🛠 Tech Stack
Python, Flask
scikit-learn, NLP
HTML, CSS, JavaScript
Gunicorn (production server)
